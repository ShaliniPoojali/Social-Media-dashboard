# Social-Media-dashboard
Analyzed nearly 700 social media records using SQL and Power BI to evaluate engagement metrics across YouTube, Facebook, Instagram, Twitter, and Snapchat. Developed an interactive dashboard with visualizations and filters to compare clicks, followers, likes, shares, and comments, identify performance trends, and support data-driven insights
# Objective
To analyze social media performance across YouTube, Facebook, Instagram, Twitter, and Snapchat to identify engagement trends and compare platform performance.
# Tools Used
SQL
Power BI
excel
# Project Features
Analyzed nearly 700 social media records.
Evaluated clicks, followers, likes, shares, and comments.
Created an interactive Power BI dashboard with visualizations and filters.
Compared engagement and performance across social media platforms.
Identified trends to support data-driven marketing decisions.
# Key Insights
Analyzed platform-wise engagement metrics to understand social media performance and identify trends.
# Conclusion
Developed an interactive Power BI dashboard to monitor social media metrics, compare platform performance, and support data-driven decision-making.
